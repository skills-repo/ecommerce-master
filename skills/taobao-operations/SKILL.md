# 淘宝/闲鱼运营方案（Taobao Operations Playbook）

> 选品 → 定价 → 上新 → 复盘的运营方法论，**不依赖 API**，淘宝企业店与闲鱼个人闲置
> 双渠道通用。API 执行层见 `taobao-product-ops` / `taobao-trade-ops` / `taobao-review-ops`。

## 能力

- 选品决策：品类四问（需求真伪/供给密度/物流友好度/合规风险）
- 定价公式：锚定价、利润带、底价的三层结构与调价触发条件
- 上新节奏：按「周上新量」选择运营形态（手动/半自动/API）
- 数据复盘：三张表（商品表现/渠道效率/问题归因）+ 周会口径

## 使用方式

```
/taobao-ops 评估「Switch 实体卡带回收转卖」这个品类值不值得做
/taobao-ops 这批货怎么定价？给我锚定价和底价
/taobao-ops 月度复盘：出三张表并给归因假设
```

## 一、选品决策（品类四问）

| 问题 | 判据 | 不过则弃 |
|------|------|---------|
| 需求真伪 | 搜索热度稳定（非事件驱动脉冲）；复购/流转频次可观察 | 一次性行情炒作品 |
| 供给密度 | 同款在售数量与价格分布是否分散（分散=有定价空间） | 价格带无差异的红海标准品 |
| 物流友好 | 体积小、值密度高、非易碎、无电池限制 | 大件/超规/含电池敏感品 |
| 合规风险 | 平台禁售清单逐条对照 | **游戏账号/代练**（淘宝禁售）、虚拟权益类 |

## 二、定价公式（三层结构）

```text
锚定价 = 近 30 天同款成交价中位数（非挂价）
我们的价 = 锚定价 ×（1 − 渠道折扣系数），并覆盖 成本×(1+损耗率) + 履约成本
底价 = 成本 + 履约成本（利润可归零，不可为负）
```

- 调价触发：曝光→点击→成交漏斗中 **点击率正常而成交率低** → 降价试探（步长 3–5%，间隔 ≥48h）
- 竞品降价不跟价，先核对其成色/配件差异

## 三、上新节奏（量级决定形态）

| 周上新量 | 形态 | 说明 |
|---------|------|------|
| < 10 件 | 人工 + 内容包 | 内容包照抄，5–8 分钟/件，零维护成本 |
| 10–50 件 | 浏览器半自动 | `browser-ops` 填到预览，发布人点 |
| > 50 件（有资质） | TOP API | `taobao-product-ops` 通道 A，限速批量 |

## 四、数据复盘（三张表）

1. **商品表现表**：SKU ×（曝光/点击/成交/转化率/毛利率）→ 找 Top/Bottom 各 3
2. **渠道效率表**：渠道 ×（上新量/成交/退货率/纠纷率）→ 决定资源倾斜
3. **问题归因表**：差评/纠纷/滞销逐条归因（选品错/定价错/描述错/履约错），一周内闭环

复盘口径：只看**已成交订单的毛利**与**退货后实际落袋**，不看 GMV 虚数。

## 红线与限制

- 不碰平台禁售类目；不做刷单/虚假交易冲数据
- 复盘结论需 ≥2 个数据周期验证才调整选品结构，避免单周噪声驱动决策
- 本技能为方法论层，不含具体命令；执行细节在 product/trade/review 三个子技能
